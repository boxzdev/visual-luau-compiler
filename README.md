# Visual Luau Compiler Online

An advanced browser-based Roblox Studio IDE, Luau runtime, 3D viewport, and GUI preview system powered by React 19, Three.js (`@react-three/fiber`), Monaco Editor, and Wasmoon (WebAssembly Lua).

---

## 📚 Documentation

All project documentation has been organized into the [`docs/`](./docs) folder:

- **[Available Elements Reference](./docs/elements.md)**: Exhaustive catalog of all 3D objects, GUI elements, UI modifiers, lighting effects, remotes, and services.
- **[Roblox Services & Methods Reference](./docs/roblox_service.md)**: Deep dive into all functional engine services, hierarchy traversal, and remote networking.
- **[Setup Guide](./docs/setup.md)**: Prerequisites, installation steps, and local development instructions.
- **[Development Log](./docs/devlog.md)**: Detailed history of all technical implementations, optimizations, and updates.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
